계산식·결측·정정공시 처리 보기
  • 반기·3분기 손익은 thstrm_add_amount(누적금액)를 사용합니다. 영업현금흐름은 thstrm_amount의 누적값을 사용합니다.
  • 개별 Q2 = H1 − Q1, Q3 = 9개월 − H1, Q4 = FY − 9개월. 앞 기간 결측이면 해당 항목을 비웁니다. 정정으로 기간 사이 기준이 달라질 수 있습니다.
  • 매출증감률 = 전년 동기간 대비 증감 / 전년 동기간 매출 × 100. 이익률 = 이익 / 매출 × 100.
  • 부채비율 = 부채 / 자본 × 100. 유동비율 = 유동자산 / 유동부채 × 100.
  • 연간·반기 ROA/ROE = 해당 기간 연결순이익 / (전년 말·해당 기말 총자산 또는 총자본의 평균) × 100. 반기는 연율화하지 않습니다. 분기 ROA/ROE는 제공하지 않습니다.
  • 분모가 0 이하이거나 값이 없으면 비율을 비웁니다. 연결 순이익 기준이므로 지배주주 ROE와 다릅니다.
  • 전체 공시 이력에서 기간별 최신 접수번호를 선택합니다. 재무 API는 매월 모든 기간을 다시 확인합니다. 원문·API 접수번호가 다르면 별도 경고합니다.
  • 2010~2014는 재무 API 미제공. 공시 원문 후보 수치는 회계기준·단위·연결 여부 검증 후 반영합니다. 확인 전 값을 자동 확정하지 않습니다.
