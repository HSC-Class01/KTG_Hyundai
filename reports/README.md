# reports

- **`hyundai-company-report.pdf`**: 기업분석 보고서(A4). 사업보고서로 읽는 현대건설의 돈 버는 구조 → 사업보고서가 중요한 이유 → 수주·수주잔고 → 원가율·수익성 → 현금·PF 보증 → 재무비율 10가지 관점 → 주가·경쟁사 → 종합 의견 순서입니다.
  에이전트(`scripts/company_report.py`)가 공시 숫자로 문장과 차트를 만들고, GitHub Actions가 매월 1일 Chrome으로 다시 인쇄합니다. 내용이 바뀌지 않은 달에는 그대로 둡니다.
- `hyundai-10y-report.html`: 예전 10개년 연간 보고서 주소입니다. 들어오면 [재무제표 대시보드](https://hsc-class01.github.io/KTG_Hyundai/dashboard/)로 이동합니다. 예전 보고서와 생성 코드는 Git 기록(커밋 `61cf2ba` 이전)에서 볼 수 있습니다.
