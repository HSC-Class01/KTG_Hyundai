# reports

- **`hyundai-company-report.pdf`**: 기업분석 보고서(A4 약 38쪽). 연구 질문과 가설을 세우고 2016~2025년 10개 사업연도 자료로 검증하는 종합 사업분석입니다.
  문제의식과 방법 → 건설업이 돈을 버는 구조 → 사업보고서를 읽는 이유 → 현대건설의 사업 구조(부문·본사와 현대엔지니어링) → 성장에 중요한 재무항목
  → 무엇이 실적을 움직였나(영업이익 변화 분해, 원가 추정 변경, 외부 요인, 현금흐름표 주석으로 나눈 영업활동현금흐름) → 10년 연표 → 번 돈의 쓰임(자본배분)
  → 미래사업 단계와 시나리오 → 종합 평가(가설의 증거 판정) → 부록(핵심 숫자 검증표 포함) 순서입니다.
  에이전트(`scripts/company_report.py`)가 공시 숫자로 문장·표·차트를 만들고, GitHub Actions가 매월 1일 Chrome으로 다시 인쇄합니다. 내용이 바뀌지 않은 달에는 그대로 둡니다.
  연도별 사건과 미래사업 단계는 `config/research.json`의 조사 내용(조사 기준일 표시)을 씁니다.
- `archive/hyundai-company-report-2026-10-v1.pdf`: 이전 판(2026년 10월 첫 판, 18쪽 — 돈 버는 구조·수주·원가율·현금·10가지 관점·경쟁사·종합 의견). 이 판을 만든 코드는 Git 커밋 `6b05cf3`에 있습니다.
